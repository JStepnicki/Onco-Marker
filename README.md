# 🧬 OncoMarker – Web App for Pancreatic Cancer Diagnosis Support

**OncoMarker** is a prototype of a clinical support system created to assist doctors in the early diagnosis of pancreatic cancer. The application provides an easy-to-use interface for entering patient data, analyzing tumor markers, and generating diagnostic results.

Developed as part of an engineering thesis, OncoMarker demonstrates how technology can enhance medical decision-making through accessible, web-based tools.

## 🔍 Main Features

- 🔐 User registration, login, and password reset
- ➕ Add and manage patient samples
- 🧪 Conduct a diagnostic analysis based on entered data
- 📧 Automatically send diagnostic results via email
- 🖥️ Simple admin panel for sample tracking

## 🛠 Technologies Used

- **Frontend**: React.js (JavaScript)
- **Backend**: Django (Python)
- **Database**: SQLite (local development)
- **Email Handling**: Django Email backend
- **Form Validation & Auth**: Django + custom logic
